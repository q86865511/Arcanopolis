# Arcanopolis

中世紀異世界都市建造經營遊戲。你是一座邊境自由城的執政官：從伐木採石與農牧起家，
建立層層加工的生產鏈，滿足居民的溫飽與信仰；同時面對異界裂隙滲出的魔物潮——
築牆設塔守城，或向冒險者公會懸賞，派人深入巢穴除掉源頭。城市壯大後，
魔力節點、法師塔與多種族移民將把這座中世紀城市推向魔法都市 Arcanopolis。

## 特色

- **生產鏈與居民模擬**：Anno/Banished 式供需經濟，資源逐級加工增值。
- **雙軌威脅應對**：塔防式守城（治標）×冒險者公會間接派遣（治本）的資源分配張力。
- **三層疊加設計**：中世紀經濟基底 → 危機威脅層 → 魔法與多種族奇幻層，逐步解鎖。
- **等距像素美術**：2:1 等距視角，AI 生圖＋自動化後處理管線。

## 技術

- Phaser 3 + TypeScript + Vite；測試 Vitest + Playwright。
- 模擬核心（`src/core`）純 TS 決定論設計，可 headless 快轉模擬做數值平衡。
- 數值全外部化於 `data/*.json` 資料表。
- 發佈路線:網頁版（itch.io）→ Electron + Steam。

## 目錄

```
src/core/     模擬核心（sim 時序、world 世界狀態、systems 邏輯系統）
src/render/   Phaser 呈現層
src/data/     型別與資料表載入器
data/         JSON 數值資料表
assets/       raw 生圖原始檔 / game 遊戲用素材 / refs 生圖參考
docs/         art-bible.md 等設計文件
```

## 快速開始

```bash
npm install
npm run dev        # Vite dev server（預設 http://localhost:5173）
```

其他指令：`npm run test`（Vitest）、`npm run typecheck`（tsc --noEmit）、`npm run build`。

平衡曲線（模擬一位會持續擴建的玩家，輸出 30 天成長曲線）：

```bash
npm run balance
```

居民移動系統效能基線（三種道路密度，輸出 CSV：elapsedMs／p95TickMs／frozenPct／searchCalls／avgSettledNodes／arrivedPct）：

```bash
npm run movebench -- --road-density 0,0.05,1 --non-road-cost 3
```

數值平衡用的 headless 快轉模擬器：

```bash
npm run simulate -- --seed 1 --ticks 3000 --sample-every 600 --buildings "farm:2,mill:1,bakery:1"
```

操作：

| 操作 | 按鍵 |
|---|---|
| 選擇建築 | 點下方選單格子，或數字鍵 `1`-`9`、`0` |
| 建築選單切換時代階段（村莊／小鎮／城市） | `[` `]` 或點頁籤 |
| 看建築資訊（成本、產出、工人、地形、解鎖條件） | 滑鼠懸停選單格子 |
| 放置 / 拆除 | 左鍵 / 右鍵（拆有住戶的民居需按兩次確認） |
| 道路工具（每格石材 1，逐格點） | `R` 或點選單最後一格；左鍵鋪 / 右鍵拆 |
| 開關市場面板 | `M`（需先蓋一座市場） |
| 暫停 / 調速 | `空白鍵` / `-` `=`（1×、2×、4×） |
| 取消選取 | `Esc` |
| 開新局（覆蓋存檔） | `N`（需按兩次確認） |

測試／驗收用 URL 參數：`http://localhost:5173/?new=1` 開全新地圖不讀自動存檔（舊存檔會在第一次日界自動存檔時被覆蓋）；
`&tick=N` 開局先快轉 N 個 tick（一天 600 tick，例 `?new=1&tick=375` 直接進入第一夜）。

## 開發狀態

開發中，**AoE2 美術五波完成，處於 MVP 可實玩狀態**：11 種資源、12 棟建築，
三段食物鏈（農場→磨坊→麵包坊）、金屬鏈（礦坑→冶煉廠→鐵匠鋪）與釀造鏈
（穀物→酒館→麥酒）可運轉，酒館是首棟 2×2 大型建築；
就業人口每日繳稅產出金幣，市場可買賣資源，遊戲可暫停調速。
頂欄資源列以圖示＋數值呈現，並顯示每日增減趨勢；人口項會直接指出成長卡在哪（缺糧／住房已滿／餓死中）。
建築依人口分三個時代階段解鎖（村莊／小鎮／城市），底欄以頁籤分類，懸停格子可看完整建築資訊。
畫面隨遊戲時刻在白天、黃昏、夜晚間平滑變化（夜晚偏藍變暗但仍可讀），頂欄顯示「第 N 天 HH:MM 時段」。
**產出與居民連動**：居民要真的走到工作地才算在職，通勤時間是實際的停工損失；
建築累積工時滿一批才交貨，頭頂進度條同時顯示它跑得順不順。
跑在程序生成的島嶼地形上，**視覺以世紀帝國 II 為北極星**：暗橄欖低飽和地表、
同地形多變體混鋪、草地/沙地散佈裝飾小物，島嶼有 0–3 階的高低起伏
（沙灘、平原、丘陵、山地），階地交界是帶光影的坡面，海岸線與草沙交界有
過渡地貌而非硬邊，全畫面套輕度降飽和與暗角統一色調。
塔防、冒險者公會、魔法與多種族尚未實作。
進度會**每個遊戲日自動存檔**到瀏覽器，重新開啟頁面自動續上次的城市。
存檔格式現為 v6（道路系統開發中：可鋪路，帶權尋路的基礎設施已落地但遊戲內暫未啟用，道路尚不影響通行與經濟）：更早版本的存檔不相容，開啟時會直接開新局並提示。

詳細進度與已知問題見 [PROGRESS.md](PROGRESS.md)。
